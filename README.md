# ST-ENDGAME v0.3

Personal SillyTavern roleplay preset with BOLT reasoning, Unified States, Bonds, emotional/narrative continuity, Pop-In graphics, and toggleable Flash behavior.

## Files

- `ST-ENDGAME v0.3.json` — current installable preset.
- `ST-ENDGAME Regex Suite v0.3.json` — standalone Unified States and Pop-In dashboard graphics.
- `build_st_endgame.ps1` — editable preset/regex build source. Its legacy FF5 identifiers remain where changing them could break existing state, regex, or prompt compatibility.

## Integration roadmap

ST-ENDGAME and ST-STATE are separate repositories only during the near-term transition. ST-STATE will become a required extension distributed with the preset. ST-FLASH will be absorbed into ST-STATE by **ST-STATE v1.0**; ST-STATE and ST-FLASH will both be fully integrated into ST-ENDGAME by **ST-ENDGAME v1.0**. The intended v1.0 result is one preset distribution with its required extension.

## Install

1. Import `ST-ENDGAME v0.3.json` as a SillyTavern completion preset.
2. Import `ST-ENDGAME Regex Suite v0.3.json` if the embedded regex scripts are absent or need replacement.
3. During the transition, install ST-STATE separately when using its external state ledger.
